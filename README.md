# build-MH
site onde você pode montar uma build pro monster hunter wilds

a ideia é essa, um site onde voce pode montar e compartilhar builds pro MHWilds, vai ter a aba inicial onde voce monta um build, uma aba com suas builds salvas e outra com builds publicas da comunidade, pra poder salvar ou compartilhar builds vc cria uma conta. a principio o site não vai funcionar como uma wishlist, mostrando os materiais pra fazer os itens, ja q o proprio jogo tem isso, e nem como um database com informações detalhadas dos itens e monstros, tem o kiranico e o fextralife pra isso. esse site é só pra montar a build e ver os status dela
